Project One — Personal Website

Web Design & Development

This project involves designing and developing a personal website using HTML, CSS, and JavaScript. The goal is to create an organized and visually appealing website that is easy for visitors to navigate.

I created a consistent layout across each page using a shared stylesheet and JavaScript navigation system. This makes the website easier to maintain and allows new pages to be added without rebuilding the navigation from scratch.

Skills used: HTML, CSS, JavaScript, Web Design
